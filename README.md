## 📊 Project Overview
This project is an Excel-based Inventory Management System designed to track stock levels, manage inventory efficiently, and automate restocking alerts. It integrates Excel features with VBA macros to streamline inventory operations.

---

## 🎯 Objectives
- Track inventory levels in real time  
- Monitor stock availability and shortages  
- Automate restocking alerts  
- Reduce manual tracking efforts  
- Improve inventory management efficiency  

---

## ⚙️ Key Features
- Inventory tracking dashboard  
- Stock level monitoring system  
- Automated restocking email alerts (VBA)  
- Organized and structured data management  
- User-friendly Excel interface  

---

## 🛠️ Tools & Technologies Used
- Microsoft Excel  
- VBA (Visual Basic for Applications)  
- Excel Formulas & Functions  
- Conditional Formatting  

---

## 📈 Key Functionality
- Tracks product quantity and stock status  
- Triggers alerts when inventory reaches threshold levels  
- Sends automated email notifications for restocking  
- Reduces risk of stockouts and overstocking  

---

## 🚀 Project Outcome
Developed an automated inventory system that improves stock management, reduces manual effort, and ensures timely restocking through email alerts.
